# AZ-900 Study Notes

Study materials aligned with the **Microsoft Certified: Azure Fundamentals (AZ-900)** exam. There are long form notes, exam-skill outlines, and practice questions.

## What is in this repo

| File | What it contains |
|------|------------------|

| [**1. Describe cloud concepts (25-30%).md**](<1. Describe cloud concepts (25-30%).md>) | Deep notes for the first exam weighting: cloud definitions, shared responsibility, cloud models (public/private/hybrid), consumption and pricing (CapEx/OpEx), and related objectives. | [**3. Describe Azure Fundamentals_ Describe Azure management and governance (30-35%).md**](<3. Describe Azure Fundamentals_ Describe Azure management and governance (30-35%).md>) | Deep notes for the third weighting: cost management (calculators, Cost Management, budgets, tags), governance and compliance, deployment and management tools, and monitoring. |
